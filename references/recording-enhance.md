# 把录屏包装成讲解段（定框 + 框内推近 + 侧栏要点）

> 原始录屏直接用会像"随便录的"。包装的目标只有一个：**让观众知道该看哪一块**。
> 手法只有三样：**固定取景框**、**框内推近**、**右栏要点**。不要更多。

## 1. 版面（1920×1080）

```
┌──────────────────────────────────────────────┐ 0
│                                              │
│  ┌────────────────────────────┐  ┌────────┐  │ 154
│  │  取景框（视频，固定不动）    │  │ 要点 01 │  │
│  │  ┌──────────────────────┐  │  ├────────┤  │
│  │  │ #cam（视频，可缩放）   │  │  │ 要点 02 │  │
│  │  └──────────────────────┘  │  ├────────┤  │
│  └────────────────────────────┘  │ 要点 03 │  │
│                                  └────────┘  │
└──────────────────────────────────────────────┘ 926
```

```css
#win{position:absolute;left:96px;top:154px;width:1372px;height:772px;overflow:hidden;border:3px solid var(--ink)}
#cam{position:absolute;left:0;top:0;transform-origin:0 0}
#cam video{display:block;width:1366px;height:766px}   /* 比边框内径小 3px，别盖住边框 */
```

**框不动、只动框里的画面**。整屏缩放会让边框跟着变粗变细，一眼假。

## 2. 框内推近（含防露白边）

```js
var s = 1 + 0.36*eio(seg(t, t0, t1));            // 1.0 → 1.36
var HW = 683, HH = 383;                          // 取景框半宽/半高
cx = Math.max(HW/s, Math.min(1366 - HW/s, cx));  // ← 不加这两行，推近必露白边
cy = Math.max(HH/s, Math.min(766 - HH/s, cy));
cam.style.transform = 'translate(' + (HW - cx*s).toFixed(1) + 'px,' + (HH - cy*s).toFixed(1) + 'px) scale(' + s.toFixed(4) + ')';
```

推镜只在**讲某一句**时发生，讲完拉回；一镜最多 3–4 段推镜。

## 3. 音画对齐：不要用脚本时间

录屏里"什么时候点了什么"和脚本执行时间**对不上**（ffmpeg 起录早于脚本、sleep 不精确），
差 2 秒很常见。正确做法是用**画面自己**定位：

```bash
ffmpeg -hide_banner -i raw.mp4 -vf "select='gt(scene,0.02)',showinfo" -f null - 2>&1 | grep -o "pts_time:[0-9.]*"
```

拿到真实切换点（例如点击发生在 4.53s），再用线性映射把"文案时间"换成"片源时间"：

```js
window.vmap = function(t){ return Math.max(0, Math.min(DUR0, 0.779*t + 2.077)); };
```

## 4. 逐帧渲染（视频必须被 seek）

```bash
node scripts/render-record.cjs "录屏R01-美化.html" 16.85 seg14.mp3 "out/R01-4K.mp4"
```

每帧的固定动作：`v.pause()` → `v.currentTime = vmap(t)` → **等 `seeked` 事件** → **两帧 rAF** → 截图。
少任何一步都会抓到上一帧（headless 下视频不会自己走）。

## 5. 批注（红框/黄笔）

- **坐标换算**：视频是 1920×1080，被放进 1366×766 的框里 ⇒ 缩放 `K=0.711`，偏移 `(96,154)`。
  写批注前先建一个 `B(vx,vy,w,h)` 函数换算，别手填。
- **框比目标大 8–12px**，正好圈住但不切边。
- **一次只亮三处以内**，跟旁白逐句出现；讲完保留或淡出都行，但**别闪烁**。
- 黄笔（斜划）只给"最后一下确认"（点 Download、按回车），别每处都划。

## 6. 右栏要点

- 结构：白底 + 3px 墨边 + 硬投影，右侧一条竖色块写编号（"框 + 挂绳"）
- 一镜 2–3 条，**常驻到片尾**（不要一条一条消失，观众来不及读）
- 文字：**书面语短句**，≤10 字，能删的字全删（"离线包 3–4 GB" 而不是"这个离线包大概有三到四个 G"）
- 同样遵守「不自造总结」：要点必须来自旁白或界面上的字

## 7. 三个常见事故

| 事故 | 原因 | 修法 |
|---|---|---|
| 推近后画面边缘露出底色 | 中心没夹紧 | 用上面两行 clamp |
| 字幕/批注压在视频上 | 视频溢出取景区 | 批注放在**框外**（右侧栏或框下方），不要贴视频内容 |
| 推镜时框也跟着变大 | 把 `transform` 加在了 `#win` 上 | 只给 `#cam` 加，`#win` 只负责 `overflow:hidden` |
