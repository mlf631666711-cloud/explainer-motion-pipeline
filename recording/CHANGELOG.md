| 新增 | 作用 |
|---|---|
| `type_unicode(s, gap=0)` | 走 `SendInput` 的 `KEYEVENTF_UNICODE` 通道。**中文、反斜杠、符号一次过**，不经过键位映射与输入法 |
| `type_human(s, gap=0.055)` | 同通道逐字投递，带字间抖动与句读停顿，用于"看着像打字"的镜头 |

| `ctrl_key(vk)` | Ctrl 组合键：**修饰键单独投递**，同批会丢 |

### 关键结论（可直接引用）

| 结论 | 数据 |
|---|---|
| 原生应用打字必须走 Unicode 通道 | 5/5 正确、12 字 **20–32ms**；老路线 **3/5** |
| 老路线的失败是**静默**的 | 中文 → 空结果 0ms；`idf.py -p COM3` → `idf.py-拍COM3`（输入法把 ` -p ` 合成「拍」） |
| 长文本用整段粘贴 | **120ms 固定**，与长度无关 |
| 鼠标本身是准的 | 5/5 命中、误差 0；差的是**客户区原点**（窗口边框 8px + 标题栏 31px） |
| 录制墙钟 | **素材时长 + 3.5s**（20s → 23.5s；6s → 9.5s） |
